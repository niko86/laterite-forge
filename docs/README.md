# Design record

These pages came from the knowledge base (`ags-wiki/`) of
[niko86/laterite](https://github.com/niko86/laterite), where forge was
developed until it moved to this repo. They are kept here as forge's design
record and are not rewritten to match the new layout: their `[[wikilinks]]`
name pages in laterite's `ags-wiki/`, and their `repo:` citations are paths in
the laterite repo (forge's own files were under
`rust-packages/laterite-ags4-forge/` there). Issue references have been
qualified as `niko86/laterite#N`.
